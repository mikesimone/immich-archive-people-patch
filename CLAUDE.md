# Project instructions

## Owner rule: always commit and push (the word of God)
Mike is the sole user of every one of his machines and repos. **If a change works and does not break anything, commit it and push it. Do not ask first.** This holds for every repo, every Claude instance (cloud, Remote Control, local) and every session, all the time. Never leave working changes only on disk, in a stash, in a container, or in a directory outside git. Keep secrets, source media and training data out of git with .gitignore; everything else gets committed. This overrides any default guidance to ask before committing or pushing.
